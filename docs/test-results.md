# 测试证据与边界

更新：2026-09-24。这里仅保留适合公开的、可复核的结果摘要；历史逐次运行记录保存在本地忽略目录，不进入开源候选。测试通过不等于两台真机或长期可用率已验收。

| 层次 | 最近一次已记录结果 | 证据边界 |
| --- | --- | --- |
| 本地代码与构建 | `npm run check`、`npm run build`、前端单测 31/31、Python 合同测试 27/27 通过 | 同一台开发 Mac；不是公网媒体证明 |
| 本地浏览器 | 常规 Playwright 双人通话 34/34 通过（含票据/消息上限两项）；无单独 TURN 凭据的一项按配置跳过；无模型 AI 音频探针 4/4 通过 | 独立浏览器上下文使用合成摄像头/麦克风，不能证明真人听感 |
| 本地 TURN | `npm run test:relay:local` 1/1 | 临时回环 coturn 的强制中转，不是外部网络 |
| 公开站点正常选路 | 2026-09-24 `npm run smoke:production` 1/1；创建、加入、离开、另一来宾重入均通过；双方选中 `direct` 并收到音视频，远端视频可解码 | 两端仍在同一台 Mac |
| 公开站点 TURN | `npm run test:relay:production` 与仅 TCP 变体各 1/1；双方选中 `relay`、接收音视频并解码远端视频 | 强制中转测试，不代表所有网络自动回退成功 |
| 跨内核对照 | 公开站点 Chromium 房主与 iPhone 尺寸 WebKit 来宾，中英文 2/2 | 模拟移动尺寸，不是真实 iPhone |
| 真实手机历史反馈 | 一次手机来宾确认听到模拟房主声音、看到画面，页面选中 TURN 中转；另一通的 Mac/iPhone 页面均报告 ICE 已连接和入站音视频 | 不足以证明真人双向可听、网络类型、稳定性或口到耳延迟 |

本轮没有测出真实口到耳延迟、异网通话成功率或服务可用率。下一关是 Mac 与真实 iPhone 使用不同网络保持至少 60 秒，双方分别确认真人语音和持续变化的视频，并记录选中路径与匿名诊断；详见[测试方案](test-plan.md)。不得把 ICE RTT 或累计丢包直接换算为听感延迟或丢包率。

AI 路径是**独立私有原型**：一人 + AI 的本地合成语音闭环、一次私有远端 WebRTC 与整段云服务商闭环曾分别通过；当前公开站点没有 AI 入口。新的流式 ASR→LLM→TTS 模式只有离线协议测试，没有真实服务商首包或真机延迟数据。测试供应商前须重新确认额度和计费状态；不要把历史单次耗时当作产品性能指标。
