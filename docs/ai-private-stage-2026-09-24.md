# 私有 AI 试验的公开边界

2026-09-24 的一次私有试验曾通过 Mac 浏览器到远端 AI 服务的 WebRTC 音频探针，以及整段云 ASR→LLM→TTS→浏览器的单轮合成语音闭环。试验结束后临时信令通道和 AI 服务已停止；没有公网 AI 入口或可供他人加入的 AI 通话网址。

这些是单次受控测试，不证明实时流式模式、真实 iPhone、异网真人听感、打断、稳定性或延迟分位数。当前 FastAPI 原型没有公网身份鉴权和账户级费用硬上限，必须保持私有/回环绑定，不可照搬到公开服务器。[AI 延迟口径](ai-latency.md)与[测试摘要](test-results.md)明确区分 API 耗时和用户听到首音频的时间。
