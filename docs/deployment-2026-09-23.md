# 测试部署摘要

更新：2026-09-24。本页仅记录公开组件及可复现的验证边界，不包含部署 ID、个人账号、共用服务器上的其他服务、余额或私有运维日志。

人际通话测试站由静态网页、Cloudflare Worker/Durable Object 信令，以及自建 coturn 组成。网页通过 HTTPS/WSS 与 Worker 交换房间状态、SDP 和 ICE；音视频由浏览器间的 WebRTC 直连，或在实际选中 relay 候选时通过 TURN 转发。长期 TURN 密钥仅在服务端配置；浏览器获得房间成员鉴权后的短期凭据。

最近一次从开发 Mac 对公开站点的自动化复核：普通选路、强制 TURN、仅 TCP TURN，以及 Chromium↔移动尺寸 WebKit 中英文场景均通过，双方能接收合成音视频；详见[测试证据](test-results.md)。这些测试没有独立物理网络出口，不能替代两台真机异网、真人双向可听/可见或长期稳定性验收。

自行部署时请使用新的 TURN 共享密钥、独立的域名与 Worker 变量、严格的成员鉴权和资源上限；[coturn 示例](../deploy/coturn/turnserver.conf.example)中的地址与密钥都是占位符。不要把示例配置、测试站 URL 或历史部署记录当作可直接复用的生产凭据。现有测试站的实际运维配置并未通过本页发布。
