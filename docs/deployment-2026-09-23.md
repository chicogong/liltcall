# 测试部署摘要

更新：2026-09-28。本页仅记录公开组件及可复现的验证边界，不包含部署 ID、个人账号、共用服务器上的其他服务、余额或私有运维日志。

人际通话测试站由静态网页、Cloudflare Worker/Durable Object 信令，以及自建 coturn 组成。网页通过 HTTPS/WSS 与 Worker 交换房间状态、SDP 和 ICE；音视频由浏览器间的 WebRTC 直连，或在实际选中 relay 候选时通过 TURN 转发。长期 TURN 密钥仅在服务端配置；浏览器获得房间成员鉴权后的短期凭据。

2026-09-27 更新原有 Vercel 网页与 Cloudflare Worker；保留原有 Durable Object、限流命名空间与 TURN Secrets，未改 TURN 服务端配置，也未部署私有 AI 服务或调用真实模型。网页生产别名 Ready，Worker 健康接口 HTTP 200，CORS 来源为网页域名。

此次自动化复核：普通选路直连、仅 TCP TURN 首轮，以及 Chromium↔移动尺寸 WebKit 中英文场景通过；随后普通强制 TURN 及仅 TCP 重复测试超时，匿名诊断中双方没有收集到候选对，并收到 TURN `486` 分配配额限制。还需核查服务器的单用户/全局配额、当前分配数和分配回收，不能据此归因于 UDP 网络限制，也不能把 TCP 首轮成功写成稳定可用；详见[测试证据](test-results.md)。这些测试没有独立物理网络出口，不能替代两台真机异网、真人双向可听/可见或长期稳定性验收。

部署上传与 Git 忽略是两个独立边界。[`.vercelignore`](../.vercelignore)明确排除私有文档、运维配置、AI 服务、虚拟环境与测试产物。此次核对发现初次 Vercel 上传包含本地私有文档（未进入网页构建输出），已重新发布精简版，并删除本轮三个多余部署副本；没有删除本地文件。最终上传清单复核不含上述私有内容。未来部署必须复核上传清单，不能只依赖 `.gitignore`。

自行部署时请使用新的 TURN 共享密钥、独立的域名与 Worker 变量、严格的成员鉴权和资源上限；[coturn 示例](../deploy/coturn/turnserver.conf.example)中的地址与密钥都是占位符。不要把示例配置、测试站 URL 或历史部署记录当作可直接复用的生产凭据。现有测试站的实际运维配置并未通过本页发布。

## 2026-09-28 中转修复

服务器端诊断把此前的 TURN `486` 定位为分配带宽预留预算冲突。调整服务端预算后，普通强制 TURN 与仅 TCP 的重复回归均通过；故障原因和成功范围见[测试证据](test-results.md)。公开记录不包含实际端口、配额、主机容量或同机服务清单。

这次调整没有放开资源上限，也不保证所有网络或视频码率。两台真机异网的真人双向验收仍未完成。
